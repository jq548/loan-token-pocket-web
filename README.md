# DINAR 

## 🚀 Quick Start

Ensure you have:

- [Node.js](https://nodejs.org) 12 or later installed
- [Yarn](https://yarnpkg.com) v1 or v2 installed

Then run the following:

### 1) Install dependencies

```bash
yarn
```

### 2) Development

Run a local server on localhost:3000.

```bash
yarn dev
```

### 3) Build

```bash
yarn build
```
